# SHERPA

> **S**erver · **H**andbook · **E**quipment-Reuse · **P**roxy · **A**gent
>
> 闲置设备变家庭/工作室服务器的半自动施工手册

**把你手上的闲置计算机，变成一台搭载ai的家庭 / 工作室服务器。**


## 你会得到什么

- **一条适配你硬件的完整路径** —— 从推荐模板出发，根据条件调整配置
- **每一步都有"怎么算成功"** —— 可执行的验收命令建议
- **每一步都有回退** —— 安全保障
- **一本坑典** —— 常见疑难解答
- **可选的服务菜单** —— 相册、影音、音乐、下载、密码库、家居自动化。目录会持续更新

## 怎么开始

**开装机向导**，回答三轮问题（大约五分钟），它会生成一份**装机清单**。
不联网、不上传任何东西。两种开法：

| 你的情况 | 怎么开 |
|---|---|
| **让 AI 助手帮你配** | 让它跑 `scripts/wizard.py` —— 你在浏览器里答完，**清单自动回到它手上**，不用你转 |
| 自己先看看 | 双击 [`wizard.html`](wizard.html) —— 答完复制或下载清单 |

```
你 → 装机向导 → 装机清单 → 你的 AI 助手 → 这本手册
     问卷、有解释   ↑接口↑       判据、验收、排障
```

**然后把装机清单连同这个仓库交给你的 AI 助手**，让它先读
[`AGENTS.md`](AGENTS.md) —— 那里写着它该怎么用这份手册，
以及**哪些事必须停下来问你**（改错了会全家断网或擦掉硬盘的那些）。

**想自己读**：从 [`00-probe.md`](00-probe.md) 进，不用通读。
出问题了直接查 [排障区](pitfalls/)，那是按**症状**索引的。

## 不需要代理？这本手册照样能用

层 2、3、4 讲的是旁路由和透明代理。**只想跑相册、影音、家庭自动化的话，
这三层整片跳过**——走 层 1 → 层 5 → 层 7 → 挑服务 → 运维。

探针第一问就是这个（[Q2a](00-probe.md#q2a-需不需要代理)）。

⚠️ 三条参考架构都含旁路由，所以这种情况**一条都不会对上，那是正常的**。
但硬件接近 [锚点 B](blueprints/b-hybrid-mini.md) 的话仍值得读它的
[「没有旁路由的话，这些代价哪些仍然适用」](blueprints/b-hybrid-mini.md#没有旁路由的话这些代价哪些仍然适用)——
**睡眠和全盘加密跟做不做代理无关。别为了对上锚点而引入代理。**

## 怎么验证这本手册

`scripts/check.sh` 做三项机械检查：脱敏、frontmatter 一致性、内链有效性。
**但它查不了内容对不对。**

真正的验收是**端到端演练**：给一份虚构的硬件条件，让一个 agent 只读本仓库，
跑一遍 `00-probe` → 选型 → 输出配置清单，全程 dry-run 不碰真机。看三件事：

1. 它能不能收敛到一个**不自相矛盾**的组合
2. 它有没有在 `needs_human` 的地方**停下来问人**
3. 它引用的 `verify` 是不是**客户端视角的那条**

这份手册被这样跑过，也被几个不同的模型分头审过——**查出来的东西大多是作者自己的**：
把一次观察写成普适定律、把上游的"建议"写成"要求"、写了一条无论如何都会通过的验收。

**你可以自己核**：[`appendix/sources.md`](appendix/sources.md) 把 112 条断言逐条标了
出处与强度（`[官方]` / `[实测]` / `[社区]` / `[推理]`），
拿不到一手来源的地方明写"取证受限"，**没有拿二手措辞冒充原文**。

## 关于示例里的地址

所有 IP、域名、MAC **都是占位符**。
**照抄不会连上任何东西** —— 这是有意的：抄错要失败得干脆，而不是恰好命中你的真机。

约定见 [`appendix/redaction.md`](appendix/redaction.md)。
